What happens when you talk

  1. Your voice goes straight to OpenAI. The browser opens a WebRTC connection to the Realtime API using a short-lived key this server hands out. Audio never round-trips through the backend.
  2. Mnemosyne answers on her own for anything she already knows — that's the voice you hear, and the blue bubbles in the transcript.
  3. For anything personal she calls the knowledge base. That fires a request back to this server, which runs the LangGraph agent over the vault: hybrid search (embeddings + full-text, fused and reranked), plus read and write tools against GitHub.
  4. The result is handed back to her, and she says it in her own words. The raw text the agent returned stays in the purple recall entry — it is a receipt, not something she said.

Notes

She speaks English and Portuguese and follows whichever you use. Memory lasts as long as this session — a new connection starts a new thread. Writes to the vault land as real commits, so anything she saves is revertible.
